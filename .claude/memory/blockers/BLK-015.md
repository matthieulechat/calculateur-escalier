# BLK-015 — Hook formateur : guillemets doubles et `;` dans le diff

**Friction** : après un `Edit`, le hook PostToolUse a reformaté tout `Plan.tsx` et `stair.check.ts` (guillemets doubles, points-virgules). `stair.check.ts` est parti tel quel dans le commit `a521b4c` (242 lignes de diff pour une vingtaine utiles).

**Cause réelle** : le hook applique un Prettier par défaut, alors que le projet n'a pas de config Prettier (style maison : guillemets simples, pas de `;`).

**Solution** : patchs via script Python dans le scratchpad (pas de hook), `git checkout` puis réapplication des seules lignes utiles, et `git diff --stat` avant de stager. Correction de fond à faire : ajouter un `.prettierrc` au projet.
