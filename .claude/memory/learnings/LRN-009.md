# LRN-009 — Texte sans collision : recherche en grille + test segment/boîte

**Pattern observé** : Pour poser un texte près d'une cible sans toucher aucun trait : générer des positions candidates en grille (distance le long + distance latérale), les trier par distance à la position idéale, garder la première dont la boîte (marge comprise) ne coupe aucun segment déjà tracé — test segment/rectangle par découpage de Liang-Barsky. Les tests se font dans le repère final, donc ça reste juste quand la vue tourne et que le texte reste horizontal.

**Contexte** : `src/dxf.ts`, numéros de marche entre foulée et jour, 4 orientations ; vérifié sur 5 escaliers sans aucun contact.

**Variante SVG (2026-10-17)** : `Labels` dans `Annot.tsx` place les cartes d'étiquettes du plan annoté par anneaux autour de la cible (rayon croissant × 12 directions, bord de la carte à la distance r pour garder la ligne de rappel courte). Les obstacles sont tous les segments tracés, cotes comprises (`dimSegs` : ligne, bande du texte, lignes d'attache), et un polygone interdit couvre l'emprise de l'escalier. Piège : en demi-tournant, `outerLine` + `innerLine` inversée laisse le jour en encoche, hors du polygone ; il faut le contour extérieur fermé. Repli sur les marges si rien n'est libre.

**Application future** : Réutiliser `hitsBox` + la grille pour toute étiquette automatique (cotes, repères) en DXF ou SVG ; accompagner d'un script qui recontrôle les collisions sur le fichier généré.

Repris dans les coupes ([BDR-027](../decisions/BDR-027.md)) : une pénalité de coût sur un côté (`dx > 0`) oriente le décalage vers l'extérieur sans changer la place préférée.
