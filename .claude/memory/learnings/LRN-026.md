# LRN-026 — Fichier reformaté en entier dans un style étranger : repartir de git

**Pattern observé** : Après une série d'Edit interrompue, `src/dxf.ts` était reformaté en entier (guillemets doubles, points-virgules, lignes coupées) alors que le projet n'en met pas : diff de ~900 lignes, et une seule modif réellement appliquée.

**Contexte** : Ajout des cotes du plan DXF ; reprise de session après interruption.

**Application future** : Vérifier `git diff --stat` en reprise. Si le diff explose, `git checkout` du fichier puis réappliquer les modifs par un script Python (remplacements exacts avec `assert s.count(old) == 1`), qui ne passe pas par Edit, et contrôler de nouveau `git diff --stat`. Voir aussi GLRN-332.
